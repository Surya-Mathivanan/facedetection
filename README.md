# Face Detection Project
  This project implements real-time face detection using OpenCV and a pre-trained Haar Cascade Classifier. It captures video from your webcam, detects faces, and highlights them in real-time.
## Introduction
  This project is a simple face detection system that uses OpenCV's CascadeClassifier for detecting faces in a video feed. It works in real-time and uses a webcam as the video source. The program draws a bounding box around detected faces.
## Features
  Real-time face detection from a webcam feed.
  Simple and lightweight with minimal dependencies.
  Adjustable face detection parameters such as scale factor and minimum neighbors.
## Technologies Used
 Python 3.x: Programming language used.
  OpenCV: Open-source library used for real-time computer vision.
  Numpy: Library for handling arrays and image data.
